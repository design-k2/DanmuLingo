DanmuLingo 弹幕翻译

DanmuLingo 是一款面向直播场景的弹幕翻译工具，支持读取 YouTube、TikTok 和 Facebook 直播间的弹幕，并通过配置翻译 API 实现弹幕翻译。软件支持通过 OBS 浏览器源展示翻译字幕，方便直播观看、内容创作及直播互动。

一、功能介绍
多平台支持：支持 YouTube、TikTok、Facebook 直播间。
弹幕翻译：支持配置翻译渠道及 API Key，通过翻译 API 实现弹幕翻译。
OBS 字幕展示：提供本地 OBS 字幕服务，可通过浏览器源在直播画面中显示弹幕字幕。
Facebook 账号登录：支持在软件内配置平台账号登录状态，以读取 Facebook 直播间内容。
本地数据存储：设置、许可证、平台登录状态及运行日志均保存在本机。
免安装运行：解压即可启动，无需单独安装 .NET 运行环境。
二、运行环境

使用前请确认系统满足以下要求：

项目	要求
操作系统	Windows 10 1809 或更高版本、Windows 11
系统架构	64 位
WebView2	Microsoft Edge WebView2 运行时
.NET	无需另行安装

WebView2 运行时说明：

Windows 11 及已更新的 Windows 10 通常已预装 WebView2 运行时。如果读取 TikTok 或 Facebook 直播间时提示缺少运行时，请前往 Microsoft 官网下载安装：

https://developer.microsoft.com/microsoft-edge/webview2/

三、快速开始
1. 下载并启动
下载 DanmuLingo 软件压缩包。
将压缩包解压到本地文件夹。
双击 DanmuLingo.exe 启动程序。

软件无需安装，解压后即可运行。

2. 激活软件

首次启动需要完成许可证激活：

打开软件激活页面。
复制页面显示的机器码。
将机器码发送给淘宝店铺「千鹤软件」。
获取许可证后，将许可证粘贴或导入软件。
点击「激活」完成授权。

激活信息保存在本机。更换电脑或主板后，需要重新申请许可证。

3. 添加直播间

在软件主界面输入直播间链接，然后点击添加。

目前支持以下平台：

YouTube
TikTok
Facebook
4. 配置翻译服务
打开「设置 > 翻译」。
选择需要使用的翻译渠道。
填写对应的 API Key。
点击「测试翻译」，确认翻译服务配置可正常使用。

请确保所选翻译服务可用，并且 API Key 具有相应的调用权限。

5. 登录 Facebook 账号

如果需要读取 Facebook 直播间，请先进入「设置 > 平台账号」完成登录，再添加相应直播间。

6. 在 OBS 中显示弹幕字幕

如果需要将弹幕翻译结果显示在直播画面中，请按照以下步骤操作：

启动 DanmuLingo 并完成相关配置。
打开「设置 > OBS 字幕」，获取字幕服务地址。
打开 OBS Studio。
在需要显示字幕的场景中添加「浏览器」源。
将 DanmuLingo 提供的地址填写到浏览器源的 URL 地址栏。
根据直播画面布局调整浏览器源的宽度、高度及位置。

完成后，即可通过 OBS 浏览器源展示弹幕字幕。

注意：OBS 字幕服务默认使用本机端口 5177。如果该端口已被其他程序占用，请在「设置 > OBS 字幕」中修改端口，并使用软件显示的实际地址配置 OBS。
四、数据存储位置

DanmuLingo 将配置数据和运行数据保存在 Windows 用户目录中。

数据类型	存储位置
软件设置与许可证	%AppData%\DanmuLingo
平台登录状态与运行日志	%LocalAppData%\DanmuLingo
API Key	使用当前 Windows 账户加密保存
数据迁移说明
API Key 使用当前 Windows 账户加密保存。
将软件或数据目录复制到其他电脑、其他 Windows 账户后，可能无法读取原有 API Key，需要重新填写。
更换电脑或主板后，许可证可能需要重新申请。
卸载软件前，如需保留配置或登录状态，请勿删除上述数据目录。
五、卸载说明

DanmuLingo 无需传统安装程序，卸载步骤如下：

关闭 DanmuLingo。
删除软件所在文件夹。

如果希望同时清除软件设置、许可证、平台登录状态及相关本地数据，可进一步删除以下目录：

text
%AppData%\DanmuLingo
%LocalAppData%\DanmuLingo


请注意： 删除上述目录可能导致许可证、设置及登录状态丢失，请提前确认是否需要备份。

六、常见问题
1. Windows 提示「已保护你的电脑」

首次运行未经广泛验证的程序时，Windows 可能显示安全提示。

如果确认软件来源可信，可点击「更多信息」，再选择「仍要运行」。

请务必先确认软件来源，并自行判断文件是否可信。

2. 提示缺少 WebView2 运行时

请从 Microsoft 官方网站下载并安装 WebView2 运行时：

https://developer.microsoft.com/microsoft-edge/webview2/

安装完成后重新启动 DanmuLingo。

3. 翻译功能无法使用

请检查以下项目：

是否已选择正确的翻译渠道。
API Key 是否填写正确。
API Key 是否有效且具有调用权限。
相关 API 服务是否正常。
是否可以通过「测试翻译」成功验证配置。
4. OBS 中没有显示字幕

请检查以下项目：

DanmuLingo 是否正在运行。
OBS 浏览器源地址是否与「设置 > OBS 字幕」中显示的地址一致。
本机端口 5177 是否被其他程序占用。
修改端口后，OBS 浏览器源是否已更新为新的地址。
5. 更换电脑后需要重新激活吗？

需要。许可证与本机硬件信息关联，更换电脑或主板后，请联系淘宝店铺「千鹤软件」重新申请许可证。
