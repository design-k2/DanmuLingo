一、运行环境
  1. Windows 10 1809 或更高版本、Windows 11，64 位系统。
  2. Microsoft Edge WebView2 运行时。Windows 11 及已更新的 Windows 10 通常已预装；
     如读取 TikTok、Facebook 直播间时提示未安装，请从 Microsoft 官网下载“WebView2 运行时”安装。
  3. 无需另行安装 .NET。

二、使用方法
  1. 解压后双击 DanmuLingo.exe 启动，无需安装。首次启动需激活：
     在激活页面复制机器码发送给销售方，收到许可证后粘贴或导入，点击“激活”。
     激活信息保存在本机，更换电脑或更换主板后需重新申请许可证。
  2. 在主界面输入直播间链接并添加，支持 YouTube、TikTok、Facebook。
  3. 在“设置 > 翻译”中选择翻译渠道并填写 API Key，点击“测试翻译”确认配置可用。
  4. 读取 Facebook 直播间前，请先在“设置 > 平台账号”中登录。
  5. 如需在直播画面中显示弹幕，请在 OBS 中添加“浏览器”源，地址填写“设置 > OBS 字幕”中显示的地址。

三、数据存放位置
  设置与许可证：%AppData%\DanmuLingo
  平台登录状态与运行日志：%LocalAppData%\DanmuLingo
  API Key 使用当前 Windows 账户加密保存，复制到其他电脑或其他账户后需重新填写。

四、卸载
  关闭程序后，删除程序所在文件夹；如需同时清除设置与登录状态，再删除上述两个数据目录。

五、注意事项
  1. 首次运行时 Windows 可能提示“已保护你的电脑”，请点击“更多信息”后选择“仍要运行”。
  2. OBS 字幕服务默认使用本机端口 5177，如被占用，可在“设置 > OBS 字幕”中修改。
